# Shared event and alert history fixture

Synthetic routes derived from the existing MCP estate, with example.net and
documentation addresses. The fixed clock is 2026-10-17 10:00 UTC. Serve unlisted
routes as 404. HTTP tests compare separate MCP and host connections for device
events, fleet events, historical alerts and what_changed without optional
services. Independent facts include an outage, a port event, a recovered alert
and an alert still open. `incomplete.json` defines a busy log that reaches the
existing 2,000-row cap inside the requested window; the result must say that
the window's start is not covered. Existing MCP tests retain detailed history,
Graylog and Unimus expectations, including config redaction and text modes.
