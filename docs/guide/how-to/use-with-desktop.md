# Use it inside DashyNMS Desktop

DashyNMS on Windows, macOS and Linux comes with its own copy of this server. Intelligence uses it to answer questions, whichever provider you choose.

- There's nothing to install or set up. The app starts its copy and gives it the connection you're signed in with.
- Your LibreNMS, Graylog and Unimus credentials stay in the app.
- The bundled copy can't be reached from the network and doesn't listen on a port.
- It's updated with the app.
- It can also explain DashyNMS itself, from the user guides it comes with.

Sensor limits, Unimus and Graylog come from the app's own settings, so the settings in this guide apply only to a server you run yourself.

To set up a provider and ask questions, see [Ask about your network with Intelligence](https://github.com/DashyNMS/desktop/wiki/Ask-about-your-network-with-Intelligence) in the Desktop guide.

DashyNMS Mobile runs the same lookups inside the app. See [its guide](https://github.com/DashyNMS/mobile/wiki/Ask-about-your-network-with-Intelligence).
